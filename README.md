# Websites

A collection of static sites. Each site lives in its own folder and runs with no build step: open the folder's `index.html` in a browser or serve the folder with any static file server.

| Folder | Site |
| --- | --- |
| [`campaign-2028/`](campaign-2028/) | **GOD 2028 — He's Seen Enough.** Satirical presidential campaign site. The page is a descent from Heaven to Earth: the sky darkens as you scroll, the nav is an altimeter, and clicking anywhere throws lightning. |
| [`sega-saturn-3d/`](sega-saturn-3d/) | **Sega Saturn — Interactive 3D Model.** A 1995 Model 1 Saturn built procedurally in three.js: orbit it, power it on, pop the CD lid, switch finishes, explode the parts, and tour numbered hotspots. Three.js is vendored, so it runs from `file://`. |
| [`ocean-wave-simulator/`](ocean-wave-simulator/) | **Open Water — Ocean Wave Simulator.** A living sea built from Gerstner waves under a procedural sky: sun glitter, whitecaps, splashes and foam, a time-of-day slider, and barrels you can drop in and watch float, drift and collide. Three.js is vendored, so it runs from `file://`. |
| [`debt-shield/`](debt-shield/) | **Debt Shield — Know before you settle.** Consumer tool for Virginians: screens a debt settlement company against Va. Code Ch. 20.1 and the FTC Telemarketing Sales Rule, links to official reputation lookups (SCC, CFPB, FTC, OAG, BBB), checks settled vs. original amounts against Virginia's 20%/30% fee cap and the federal advance-fee ban, estimates real savings after fees and taxes, and drafts a complaint. Runs entirely in the browser. |
